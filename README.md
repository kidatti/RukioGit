# RukioGit

RukioGit の配布用リポジトリです。

## ダウンロード

配布ファイルは [Releases](https://github.com/kidatti/RukioGit/releases) に掲載します。
現在、配布ファイルは準備中です。

各リリースの説明で対応環境と導入手順を確認し、Assets から配布ファイルをダウンロードしてください。

## 不具合・お問い合わせ

不具合の報告やご要望は [Issues](https://github.com/kidatti/RukioGit/issues) にお寄せください。
不具合の報告には、利用バージョン、動作環境、再現手順を記載してください。
個人情報や認証情報は記載しないでください。
